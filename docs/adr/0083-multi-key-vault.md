# ADR-0083: 快评密钥库——一把密钥=一份完整配置束，点选即切换，明文永不回显

## 状态

Accepted (2026-10-17)

## 背景

快评（浏览器扩展「快评」按钮用的单次 LLM 调用）此前只能持有**一把**密钥：`data/quick-eval.json`
是单对象 `{provider, model, baseUrl, apiKey}`，每次保存整体覆盖。用户有多把密钥
（Agnes 中转、OpenAI 官方、公司代理额度等）轮换使用的需求，粘贴新密钥就冲掉旧的。

交互原型（`.scratch/api-key-vault-proto/index.html`，2026-10-17 确认）钉住了 UI 形态，
本 ADR 记录其下的八个决策。相关既有边界：ADR-0073 决议 1（`mode` 单一真值源在
`career-ops:config`，快评存储只放快评字段）继续有效，本次不动这条分界。

## 决策

1. **一把密钥 = 一份完整配置束（密钥束）**：名称 + provider + 模型 + Base URL + 密钥串。
   启用哪把，整套属性一起切换。provider 不再是页面上的全局单选——配置页「AI 引擎」区
   mode==="key" 分支顶部那五张 provider 大卡**删除**，provider 收进添加/编辑表单内。
   名称由用户起，用于区分同一 provider 下的多把密钥；不限制密钥数量（本地单文件）。
2. **存储模型 v2 + 自动迁移**：`data/quick-eval.json` 变为
   `{version: 2, keys: [{id, name, provider, model, baseUrl, key, addedAt, lastTest}], activeId}`。
   首次读到 v1 单密钥文件时，把它迁为第一把名为「默认」的密钥并置为使用中，
   旧文件改名 `quick-eval.json.v1.bak` 留回滚窗口（含明文密钥，仍在 gitignore 的 `data/` 内，
   受影子备份规程覆盖）。原子写沿用 `writeQuickConfig` 现有做法。
3. **明文密钥永不回显（不变量延伸）**：读接口维持「永不返回 apiKey」。列表渲染所需的
   打码串（`sk-4f8…a91e`，前 6 + 后 4，不可还原）由服务端派生返回。编辑表单的密钥字段
   **留空 = 保持原密钥不变**，填入非空值 = 整体替换；不提供任何形态的明文回显路径。
4. **切换即时生效，绕开底部保存条**：点密钥行 = 服务端写 `activeId` + toast 回执
   「快评改用 XX · 已生效」。保存条只承载其它字段的脏状态；「使用中」徽标显示的
   永远已是事实，不存在「显示了但没保存」的歧义态（这正是原型避开保存条的原因）。
   删除使用中那把 → 自动切到剩余第一把并同样即时落盘；密钥库清空后
   `/api/quick-eval` 照旧返回 `quickEvalNotConfigured`，扩展提示语不变。
5. **测试连接进 v1，真调端点**：新增 `POST /api/quick-eval/test`，接受 keyId 或表单草稿
   密钥串，向对应端点发一次最小请求，返回成功/失败与原因分类（401 / 404 / 超时）。
   **草稿测试不落盘**——请求里的密钥串只在本次调用内使用，不写任何文件。
   行的 `lastTest` 徽标（✓已验证 / ✗上次失败）以此为数据源。
6. **浏览器扩展零改动**：扩展只调 `/api/quick-eval`，服务端 `activeId` 变了对它透明；
   快评结果不显示「本次用的哪把密钥」（评估过，v1 不做）。
7. **CLI 引擎档不共用本心智**：mode==="cli" 的「工具 + 模型」选择保持现状，不做成可存
   多套的配置束。两套心智各管各的档位，防止范围互相传染。

## 后果

- 密钥的写入路径从一条（保存覆盖）变成三条（新增 / 编辑 / 删除），全部经
  `/api/quick-config` 扩出的接口，落盘仍只有 `data/quick-eval.json` 一处。
- 「配置页每次保存都悄悄换掉了我的密钥」这条投诉路径不复存在：新增密钥存入后
  **不自动启用**，当前使用的那把不变，除非用户点了它。
- v1→v2 迁移是一次性、只增不改的：v1 文件被重命名而非删除，任何迁移 bug 都可以从
  `.bak` 恢复；消费方（`quick-eval.ts` + 两个 API 路由）全部收在 `readQuickConfig`
  一个入口后面，界面层不接触文件格式。
- 回滚：删除 v2 文件、把 `.bak` 改回原名即回到单密钥世界；前后端字段各自向后兼容
  （读接口新增字段，旧前端忽略）。
