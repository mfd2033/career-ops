# 05: 报告页跳转

**What to build:**

用户点击已评估徽章（或评估完成后的结果入口），直接在新标签页打开本地 web 上该职位对应的评估报告页，看到完整 A-G 维度和机器摘要，无需在 web 端重新翻找该职位。跳转端口取自已探测到的本地服务，点击一次即达。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 点击已评估徽章 → 新标签页打开本地 web 对应报告页（携带该职位的报告号）
- [ ] 打开端口取自已探测的本地 web 端口，而非硬编码；本地服务未运行时给明确提示且不产生坏链
- [ ] 新标签页报告正确渲染，URL 命中本地服务，报告内容与 web 端侧评价结果一致
