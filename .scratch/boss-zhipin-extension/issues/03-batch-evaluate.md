# 03: 列表页批量就地评估 + 进度

**What to build:**

用户可以在 BOSS 搜索列表上勾选多个职位，一次发起批量评估；评估期间在插件弹窗里逐条看到「待评 → 进行中 → 完成+评分 / 失败」的实时进度，结束后对应职位卡片自动刷新为已评估。用户不再需要一个个复制 URL 到 web 管道页手动评估。

**Blocked by:** 01, 02

**Status:** ready-for-agent

- [ ] content script 在 BOSS 列表职位卡片注入复选框与选中态；多处勾选后可汇总所选职位 URL
- [ ] 弹窗收集选中 URL，调用既有批量评估接口（复用 config 页已配的 CLI + 模型），不重复选择评估配置
- [ ] 弹窗解析评估接口下发的流式事件，逐职位渲染 待评估 / 进行中 / 完成（含评分）/ 失败
- [ ] 评估完成后自动重拉已评估映射，刷新对应职位徽章；评估中的职位入口禁用，避免重复触发
