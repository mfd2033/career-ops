# 04: 详情页单职位评估

**What to build:**

用户打开某个职位详情页时，页面上有「评估本职位」入口，点一下即对该职位单独评估；评估期间按钮禁用防重复，完成后该职位状态就地刷新，可跳转看报告。单职位评估与列表批量评估共用同一评估引擎，结果一致。

**Blocked by:** 01, 02

**Status:** ready-for-agent

- [ ] 详情页注入「评估本职位」按钮，仅出现在单个职位详情场景
- [ ] 点击后以单个职位发起评估（复用 config 已配 CLI + 模型），进度在弹窗展示
- [ ] 评估中按钮禁用；完成后刷新该职位的已评估徽章/结果状态
